Networking checklist

Flat LAN; WSJT-X multicast by band port; N1MM external broadcast to WIMS; see docs/plan/wims_networking.md.

  • WSJT-X UDP Server = fleet multicast (e.g. 224.0.0.73), not 127.0.0.1
  • WSJT-X Outgoing interface = contest LAN NIC (never blank / @Invalid() / loopback)
  • N1MM Broadcast Data → Contacts + Radio → 127.0.0.1:12060 + N1MM agent
  • N1MM WSJT/JTDX UDP reader OFF (digi → N1MM is agent Log; avoid double-log)
  • Host firewall allows console TCP 8787 from operator PCs / VMs
  • Site server presence UDP 8788 (multicast) — second server refuses; agents show clickable console links
  • Unique WSJT-X --rig-name / UDP id per instance
  • One site server only — seats run agent + N1MM/WSJT-X, not a second wims.server
