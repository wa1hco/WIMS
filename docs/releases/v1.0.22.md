# WS Hub 1.0.22

What changed since 1.0.21. A first start on one PC now runs the site server itself when none is already on the network, including a station that only has WSJT-X. The console window also works with Ubuntu's snap Firefox. A person still starts every transmit.

## Updates

**A single PC just works.** After a fresh install, double-click **WS Hub**. If no site server is already on the network, this PC starts one and opens the console at `http://localhost:8787/`. That includes a WSJT-X-only station, which used to hide the Site server option and look for a server on another machine. There is no built-in address of some other PC.

**Several PCs on one network** still share one server. If this PC already remembers a server on another host, or one is found on the LAN, that server is used and a second one is not started. Seat agents follow if the chosen server later changes.

**Snap Firefox on Ubuntu.** The dedicated console window now keeps its profile in a folder the snap is allowed to write (`~/snap/firefox/common/…`). If that window still does not stay open, the console opens in the usual browser instead. Two starts at the same moment no longer fight over the same profile.

## Installing from this page

**Linux.** Download `wims-1.0.22-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.22-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
