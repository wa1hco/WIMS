# WS Hub 1.0.18 (formerly WIMS)

What changed since 1.0.17. WIMS is now called **WS Hub**, with a new icon. Double-click **WS Hub** on the Desktop or in the Start menu (Linux: the app menu). A person still starts every transmit.

## New name and icon

**WS Hub.** The Desktop icon, the Start menu entry, the Linux app menu entry, and the launcher window title say **WS Hub**. The icon is white **WS** over **HUB** on the same blue square, in the same style as WS Skim.

**One icon, not two.** The first time the updated launcher opens, it renames an existing **WIMS** Desktop icon to **WS Hub**. Adding the icon again (Linux: **Add WIMS to Desktop**; Windows: **Add WIMS to Desktop.bat** or **Install-Wims.cmd**) also removes the old **WIMS** icon and Start menu entry. If the old picture still shows after an update, log out and back in so the desktop reloads it.

**Updates keep working.** The GitHub project is now [wa1hco/WS-Hub](https://github.com/wa1hco/WS-Hub). GitHub forwards the old WIMS address, so the **Updates** list in 1.0.17 finds this version. Folder names, file names, and settings are unchanged.

## Installing from this page

**Linux.** Download `wims-1.0.18-linux-x86_64.tar.gz` and unpack it. Open the folder, open **scripts**, and double-click **Add WIMS to Desktop**. Then double-click **WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**.

**Windows.** Download `wims-1.0.18-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.

## Operate roster

**Country.** A **Country** column shows each station's DXCC entity (Uruguay for CX4BAN), so you can read it without knowing prefixes.

**One needed word.** The badge that said **needed** names one reason: **grid**, **state**, **DXCC**, **CQ zone**, **ITU zone**, **continent**, or **call**. When that word is shown, the extra **mult** badge is hidden. Contest rows have no place word, so **mult** stays there.

**Show menu.** The **needed only** checkbox is a **show** menu: **Needed**, **Needed and CQ**, **Needed and CQ or 73** (stations free to call), and **All**.

**Approximate heading.** When a station has no grid, **Az DX** and **km** use the middle of its DXCC country and show as approximate, for example `~260°`. No grid square is guessed.

**Remembered grid.** WIMS keeps the last grid it heard for each call. A tail-end with no grid gets that square on the roster and on the record WIMS forwards, and **Work** fills WSJT-X's DX Grid from it. A rover square from an earlier hearing is marked **grid assumed**. A three-letter KG4 call counts as the United States.

**Call roster rules.** The contest-rules line under **Call roster** moved into a tooltip. Hover the heading to read it.

**TX groups** show only when there is something to know: an overlap or a blocked Work is never hidden. The Work and Halt status line is short (`Working K1ROV/R on flex`); hover it for the details.

## Goals and logs

**Checklist** replaces WSJT-X Colors under Just operating, and adds continent and zone lines.

**Worked but not confirmed.** Award and checklist goals flag a place that is worked but not confirmed when a new station is heard, and skip it when that station was already worked in the goal's scope. WIMS reads the LoTW file GridTracker keeps on this PC to tell what is confirmed.

Logging a contact clears that station's **mult** on the roster.

## Spotted (DX cluster)

Operate has a **Spotted** list of DX cluster spots on any band, separate from the live roster. It uses the roster's columns and the same needed word. A spot on a band with no WSJT-X running is marked **QSY** and scores a little lower. Checkboxes for **SSB**, **CW**, **FT8**, **FT4**, and **Other** filter the list by mode. A click selects the station and does not transmit.

## Antennas

The seat checkbox **Antennas** reads rotator headings from hamlib `rotctld`, and Operate shows the antenna, its heading, and whether it is connected.

## Launcher

- **Restart site server** restarts the server on this PC only. A server on another PC is left running.
- The site console window remembers its size and place on this PC.
- Linux: a new user double-clicks **Add WIMS to Desktop** in **scripts**. A missing Python or Tk is a plain message that names the package.
