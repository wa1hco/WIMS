# WS Hub 1.0.19

What changed since 1.0.18. On Linux, **Install WS Hub** now puts the program in your home folder, so the download can be deleted. A person still starts every transmit.

## Linux install

**One place for the program.** Unpack the download anywhere, Downloads is fine. Open the unpacked folder, open **scripts**, and double-click **Install WS Hub** (it was called Add WIMS to Desktop). WS Hub copies itself to `~/.local/share/ws-hub`, the place Ubuntu uses for programs a person installs for themselves, and the **WS Hub** icon on the desktop and in the app menu starts that copy. When the message says so, delete the downloaded folder and the `.tar.gz`. They are not needed again.

**Installing again.** Doing the same with a newer download replaces the copy in `~/.local/share/ws-hub`. The old copy is replaced only after the new one is fully in place, so a failed copy leaves the old one working.

**Your settings stay.** Settings and remembered data are not in the program folder. They live in `~/.config/wims` (log choice, contest rules, cluster settings, heard grids, seats), `~/.local/share/wims` (seat profile, browser profile), and `~/.local/state/wims` (console window). Installing or updating does not touch them. The launcher's details log in the program's `scratch` folder is carried over.

**A git clone stays put.** If the folder is a git clone, **Install WS Hub** does not copy it. The icon points at the clone, as before.

**Update from the window.** A copy in `~/.local/share/ws-hub` can now update itself. In **Updates**, pick the version and click **Install this update**. WS Hub downloads that release's Linux file, checks it against `SHA256SUMS`, and swaps it in. **Go back** returns to the copy it replaced. Windows copies that are not git clones still open the release page.

## Icons

**No leftover WIMS icon.** Installing removes an old **WIMS** icon on the desktop and in the app menu when it starts WS Hub, whatever form it has: the 1.0.x icon, the oldest icon that ran `python -m wims.launcher`, or one whose folder is the WIMS program. Icons for other programs are left alone.

**An icon that points at Downloads** (from installing 1.0.18 there) is rewritten to point at `~/.local/share/ws-hub`.

## Installing from this page

**Linux.** Download `wims-1.0.19-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.19-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
