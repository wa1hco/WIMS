# WS Hub 1.0.21

What changed since 1.0.20. The update button at the top of the WS Hub window now does the same job as **Install this update** on a Linux download, so you no longer need two buttons for one action. A person still starts every transmit.

## Updates

**One update action.** On a Linux install in `~/.local/share/ws-hub`, the button next to “Update available” is **Install update** (or **Install 1.0.21** when that version is known). It downloads that release, checks `SHA256SUMS`, and replaces this copy the same way **Install this update** does. The previous copy is kept so **Go back** still works.

**Git clones** still pull with one click; the button is now **Update WS Hub**.

**Windows copies that are not git clones** still open the GitHub Releases page; the button is now **Download update**.

**Install this update** in the Updates list is unchanged: pick a version, including an older one, and install that.

## Installing from this page

**Linux.** Download `wims-1.0.21-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.21-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
