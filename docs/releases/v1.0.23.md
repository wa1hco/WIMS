# WS Hub 1.0.23

What changed since 1.0.22. Check logs now lives only inside WS Hub, so remembering the app name is enough. A person still starts every transmit.

This release is not published yet.

## Updates

**Check logs is in the app.** The separate Desktop and app-menu **Check logs** icons are no longer created. After you start WS Hub once, leftover icons from an earlier version are removed if they started this program's checker. Other files with that name are left alone.

**Check logs on this PC.** In the WS Hub window, next to **Open site console**, **Check logs** compares the logs on this PC and opens the report in the browser. That works on any seat, including a PC that is not running the site server.

**Check logs on the server.** The **Check logs** button on the console's **Log** page still compares the logs on the site server's PC.

## Installing from this page

**Linux.** Download `wims-1.0.23-linux-x86_64.tar.gz` and unpack it anywhere. Open the folder, open **scripts**, and double-click **Install WS Hub**. If the file manager asks once, choose **Allow Launching**, **Execute**, or **Run**. Then delete the download and double-click **WS Hub**.

**Windows.** Download `wims-1.0.23-windows-x86_64.zip` and extract it to `C:\WIMS`. Open `C:\WIMS\scripts\windows` and double-click **Install-Wims.cmd**. Then double-click **WS Hub**.
